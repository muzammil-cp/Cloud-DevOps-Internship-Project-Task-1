# Cloud Development Environment Initialization

## Cloud Computing & DevOps Internship — Task 1

This project establishes a Linux-based Cloud and DevOps development environment with Git, GitHub, SSH authentication, networking tools, Bash automation, and professional documentation.

## Objectives

- Configure a Linux development environment
- Install essential DevOps tools
- Configure Git and GitHub
- Configure SSH authentication
- Practice Linux commands
- Practice networking commands
- Automate project initialization using Bash
- Maintain professional technical documentation

## Technologies

- Ubuntu Linux
- Git
- GitHub
- OpenSSH
- Bash
- Curl
- DNS utilities
- Networking utilities

## Documentation

- `docs/installation-guide.md` — Linux and development environment installation
- `docs/linux-commands.md` — common Linux command reference
- `docs/networking.md` — networking fundamentals and verification commands
- `docs/git-github.md` — Git and GitHub workflow
- `docs/troubleshooting.md` — common Git, SSH, Linux, and networking issues
- `notes/task-1-completion.md` — completion summary
- `notes/evidence-index.md` — screenshot evidence mapping

## Automation

- `setup.sh` — Bash automation for initializing a standard DevOps project structure
- `scripts/system-info.sh` — collects basic Linux system information

## Security

- Private SSH keys are not stored in the repository.
- Credentials, tokens, and environment secrets are excluded through `.gitignore`.
- Only safe example configuration is stored under `config/`.

## Evidence

Practical screenshots are stored under `screenshots/` and document Linux setup, Git/GitHub, SSH authentication, networking, project structure, Bash scripts, and final Git status.

## Task Result

Task 1 establishes the Linux, networking, Git/GitHub, SSH, Bash, and documentation foundation used for subsequent Cloud/DevOps internship tasks.
